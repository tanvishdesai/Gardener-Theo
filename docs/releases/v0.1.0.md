A desktop garden for your Claude Code agents: repos are beds, agents are plants, you are the gardener.

![The demo garden at midday](https://github.com/tanvishdesai/Terrarium-TD/raw/main/docs/garden.png)

Try it first in your browser, with simulated agents: https://terrarium-td.vercel.app

## Downloads

| System | File |
| --- | --- |
| Windows 10/11 (x64) | `Terrarium-Setup-x64.exe` |
| macOS (Apple Silicon) | `Terrarium-mac-arm64.dmg` |
| Linux (x64) | `Terrarium-linux-x86_64.AppImage` |

## Requirements

- **Claude Code**, installed and logged in: run `claude` once in a terminal and sign in. Every plant uses that login; Terrarium stores no credentials.
- **git**.
- **GitHub CLI (`gh`)**, optional: logged in, it lets the Harvest tab open pull requests.

## These builds are unsigned

Your system will warn you the first time you open Terrarium.

- **Windows:** SmartScreen shows "Windows protected your PC". Click *More info*, then *Run anyway*.
- **macOS:** the first open shows a warning. On macOS 15 and later: try to open Terrarium once, then go to System Settings → Privacy & Security and click *Open Anyway*. Or, in Terminal:
  `xattr -dr com.apple.quarantine /Applications/Terrarium.app`
- **Linux:** make the file executable and run it:
  `chmod +x Terrarium-linux-x86_64.AppImage && ./Terrarium-linux-x86_64.AppImage`
  AppImages need FUSE 2 (`sudo apt install libfuse2t64` on Ubuntu 24.04, `libfuse2` on 22.04). If it quits straight away with a sandbox error (Ubuntu 24.04 restricts it), start it with `--no-sandbox`.

## Known limits

- The macOS and Linux builds are new and lightly tested. Please open an issue if something breaks.
- Pull requests on hosts other than GitHub: Terrarium stops after the push.
- No auto-update yet: download new versions from this page.
